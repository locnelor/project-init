## 技能

### turbo

turbo是一个基于pnpm的monorepo工具，用于管理和运行多个项目。

### @scripts/turbo-run

重构turbo的run命令，支持运行项目的选择。

### @internal/vite-config

vite配置库，提供基础的vite配置，包括应用、库和样式等。

### @internal/tailwind-config

tailwind配置库，提供基础的tailwind配置。

### @internal/tsconfig

tsconfig配置库，提供基础的tsconfig配置，包括编译器选项、类型声明等。
